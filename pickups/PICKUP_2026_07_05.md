## Session 2 (later — GPU runs, diagnosis, gate/withhold design)

### Completed (Session 2)

1. **Re-ran the full 4 conditions at 20ep successfully** (`results/_jobs/full.sbatch`,
   `--exclude=ins082`, verified GPU first via interactive `srun`). Coarse net pretrained
   (test_acc 0.62). Results (retention/AIA recomputed):

   | condition (20ep) | avg_acc | retained | AIA | just-learned task0 |
   |---|---|---|---|---|
   | a_baseline | 0.084 | 0.0000 | 0.198 | 0.53 |
   | b_oracle (concat) | 0.095 | 0.0298 | 0.298 | 0.97 |
   | c_soft (0.3) | 0.095 | 0.0048 | 0.281 | 0.97 |
   | d_trained (62%) | 0.074 | 0.0000 | 0.213 | 0.69 |

   Graded hypothesis PARTIALLY holds: oracle > soft > baseline on retention. **d_trained
   flatlines at/below baseline** — the trained coarse net (62%) is too weak/wrong (38% of
   the time it feeds the wrong superclass); soft-0.3 is actually higher-fidelity (always
   argmax-correct). Effect is small and **seed-noisy** (oracle retained 0.016 one run,
   0.030 another). `comparison.png` generated (20ep).

2. **Diagnosed the low first-task accuracy (user flagged) — NOT a bug.** Pipeline is all
   standard (CIFAR ResNet 3×3 stem, aug, cosine schedule, eval-mode BN). Train-vs-test
   diagnostic (`results/_jobs/diag_task0.py`): at **20ep the model hasn't even fit
   train** (train 0.56 ≈ test 0.54 = underfit); at 60ep train 0.83 / test 0.67 (fit, but
   modest data-limited ceiling — only 5k imgs to learn features from scratch on task 0).
   The baseline diagonal *climbs* 0.53→0.84 across tasks because the backbone accumulates
   feature learning over the sequence. **→ 20ep conflates "failure to learn" with
   forgetting; bumped to 60ep.**

3. **Conceptual diagnosis — why even oracle barely reduces forgetting (the key insight).**
   (a) The coarse→fine *readout* lives in the same **plastic** weights that forget, so a
   perfect signal is read out through an overwritten mapping. (b) `concat` *nudges* logits
   additively (a few units) but is drowned by the tens-of-units recency-bias gap, and
   never *restricts* the output space (`predict()` argmaxes over ALL seen classes across
   all superclasses). This isn't real CLS: the coarse signal is an input to one monolithic
   plastic net, with **no protected/stable pathway** — the "skill to use the hint" is
   itself forgotten. User aligned on this framing (CLS-inspired first pass).

4. **Designed + IMPLEMENTED two eval-time variants** (config swaps, no training-loop
   rewrite; both build + verified locally):
   - **(A) withhold** — `conditioning.eval_withhold: true`. Concat trained WITH oracle,
     but fed **uniform** (no info) at eval. Ablation: is the concat benefit purely the
     test-time vector? (Config `configs/b_oracle_withhold.yaml`.)
   - **(B) gate** — new conditioning mechanism `gate`. Coarse used **only at inference**
     as a multiplicative log-prior: `logit_f += log(coarse_dist[superclass(f)])`. Oracle
     one-hot → **hard mask** to the true superclass (5 fine classes); soft/trained →
     graded prior; uniform → no-op (recovers baseline). Sweeps fidelity via `coarse.source`.
     Unit-tested: hard-masks correctly, uniform is argmax-preserving. Configs
     `configs/e_gate_{oracle,soft,trained}.yaml`.
   - **Rationale:** gate gives the coarse scale STRUCTURE (constrains output) instead of
     being a plastic input the model must re-learn to exploit. It's the CLS-faithful test.

5. **Bumped epochs:** `configs/base.yaml` `train.epochs_per_task` 20→60,
   `coarse_train.epochs` 30→60 (stronger trained signal; 60ep coarse net = 0.659, only
   marginally better — small CNN caps ~66%).

### Completed (this session)

1. **THE KEY RESULT — `gate` (structural coarse) reduces forgetting; `concat` (coarse as
   input) does not.** From job 11117190 (60ep, all 8 conditions). retained = mean old-task
   accuracy across the run:

   | condition (60ep) | avg_acc | retained | old-evals>0 | final old>0 |
   |---|---|---|---|---|
   | a_baseline | 0.088 | 0.000 | 0/45 | 0/9 |
   | b_oracle (concat) | 0.096 | **0.000** | 0/45 | 0/9 |
   | b_oracle_withhold (A) | 0.017 | 0.000 | 0/45 | 0/9 |
   | c_soft / d_trained | 0.096 / 0.086 | 0.000 / 0.000 | 0/45 | 0/9 |
   | **e_gate_oracle (B)** | **0.198** | **0.180** | **45/45** | **9/9** |
   | e_gate_soft | 0.094 | 0.000 | 0/45 | 0/9 |
   | e_gate_trained | 0.090 | 0.007 | 35/45 | 6/9 |

   - **Same perfect oracle signal → 0.000 retention as a concat input vs 0.180 as a gate.**
     The gate hard-masks fine logits to the true superclass; retention is real (varied,
     recency-decaying: task0 holds 0.48→0.61→0.67 early), not a chance-within-5 floor.
   - **(A) withhold ablation confirms concat was a test-time crutch:** concat trained on
     oracle but fed uniform at eval collapses to 0.017 (below baseline, even t0=0.19).
   - **Gate needs a PEAKED prior:** e_gate_soft (smooth=0.3) → 0 retention (its ~3.9-logit
     prior gap can't beat the tens-of-units recency gap); e_gate_trained (peaked when
     confident) → partial (35/45). Fidelity-under-gating = confidence, not argmax-correctness.
   - `results/comparison_gate.png` generated.

2. **Diagnosed WHY absolute numbers stay poor (user: "results are quite trash").** Two

   post-mask old-task values are 0.01–0.28, mostly wrong even within the correct 5. (b)
   FIXABLE — weak/data-limited features.

3. **Ceiling diagnostics (`results/_jobs/diag_ceiling.py`, job 11318758):**
   - **From-scratch fine backbone, JOINT (all 100, non-continual): 0.770.** So the arch/data
     ceiling is 0.77; continual ~0.09–0.20 ⇒ **the whole gap is forgetting, not features.
     Huge headroom.**
   - **Frozen coarse-net feature probes (joint fine acc by depth):** block1=0.461,
     **block2=0.573**, block3(penult)=0.476. Confirms the user's intuition: the MIDDLE layer
     preserves more fine info than the coarse-specialized penultimate layer (inverted-U).
     But frozen coarse features cap at ~0.57, ~20 pts below the 0.77 fine backbone.

4. **Built + ran the frozen-features experiment — REFUTED the "stable features help"
   hypothesis.** New `FrozenCoarseBackbone` (coarse net truncated at block 2 = 4096-d,
   frozen, BN fixed, no grad; only a linear fine head trains). The 2×2 (job 11319272, 60ep):

   |  | no gate | gate (oracle) |
   |---|---|---|
   | **plastic features** | avg 0.088, ret 0.000 | avg **0.198**, ret **0.180** |
   | **frozen block-2** | avg 0.083, ret 0.000 | avg 0.099, ret 0.018 |

   **Frozen HURT.** Lessons: (i) **forgetting is HEAD-level, not feature-level** — freezing
   features gave 0 retention benefit (frozen no-gate still 0.000); the culprit is masked-CE
   suppressing old-class logits in the linear head. (ii) **Given the gate, feature QUALITY
   dominates, stability is irrelevant/harmful** — plastic (0.77 ceiling) beats frozen coarse
   (0.57) 10× on gate-retention (frozen forgets 0.04 even one task later vs plastic 0.18).
   **Frozen-coarse-features is a dead end.**

5. **CONCLUSION of the whole line:** coarse-as-structure (gate) roughly doubles retention
   (0.088→0.198) but hits a hard wall — **within-superclass head forgetting, which coarse
   info is structurally incapable of touching.** Coarse-alone caps ~0.20. Beyond that needs
   head-level CL machinery (out of the original "does the coarse signal help" scope).

### Reference: the mechanistic story (for the write-up)
- Coarse signal as an **input** (concat) → 0 forgetting benefit: the "skill to use the hint"
  lives in plastic weights and is overwritten (same as the fine knowledge).
- Coarse signal as **structure** (gate = hard-mask to superclass) → real benefit (0.18
  retained, 2.2× avg_acc): it constrains the output space, can't be forgotten.
- Ceiling is 0.77 (joint) so the gap is forgetting. Forgetting is **head-level** (masked-CE),
  not feature drift — proven by frozen features giving 0 benefit.
- Residual wall = **within-superclass forgetting**, which coarse info cannot address.
  Coarse-alone caps ~0.20. This is the clean, honest thesis result.

### Completed (this session)

1. **Settled all design decisions (recorded in `DESIGN.md`).**
   - Coarse signal is ALWAYS a distribution over 20 superclasses (`FloatTensor[B,20]`
     or `None`); oracle = one-hot. This unifies the 4 conditions behind one interface.
   - Two orthogonal, registry-resolved config axes: `coarse.source`
     (`none`/`oracle`/`soft`/`trained`) × `conditioning.mechanism` (`concat`/`aux_loss`).
   - **Soft proxy (c) = mass-mixing, single knob** `coarse.soft.smooth`:
     `dist = (1-smooth)*one_hot + smooth*uniform`, 0→oracle, 1→uniform. Chose this
     over label-flip; label-flip is deferred to a future "noisy oracle" 5th condition
     as its own `CoarseSource`.
   - **Class-IL head = fixed 100-way**, loss masked to seen classes, eval argmax over
     seen set only.
   - **Condition (d) coarse net = trained once upfront, frozen**; `coarse.trained.
     continual` is a dormant hook (raises NotImplementedError if set true).

2. **Built the full `coarsecl/` package.** Registry-driven so a 5th condition = one
   new `CoarseSource` class + one config value, no training-loop edit. Backbone is a
   CIFAR ResNet-18 (11.2M params), identical across all conditions.

3. **Verified everything short of a real run.**
   - All 4 configs build; baseline correctly auto-resolves to `none` conditioning.
   - Forward/backward for every source + both mechanisms; masking provably blocks
     predicting unseen classes; distributions normalize to 1.
   - CIFAR fine→coarse map validated (20 superclasses × exactly 5 fine each).
   - Trained-source checkpoint roundtrip with a verified-frozen net.
   - **Full smoke run on real CIFAR-100 completed** (`configs/smoke.yaml`, 2×50, 1
     epoch): data→train→eval→metrics→artifacts all work. `acc_matrix.csv` is
     lower-triangular; `metrics.json` embeds the resolved config. Smoke numbers
     (avg_acc 0.27, task-0 forgotten to 0.0) are a degenerate-config artifact, NOT a
     real result — expected for 50-class chunks at 1 epoch.

4. **Env + repo setup.** Created `.venv` (torch 2.8.0 **CPU build** — `cuda False`
     here; `device: auto` picks GPU on a GPU node). `git init -b main`; all files
     **staged but NOT committed** (user prefers to commit themselves — they rejected
     an auto-commit this session).
